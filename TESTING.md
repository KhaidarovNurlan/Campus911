# Отчет по тестированию мобильного приложения Campus911

## 1. Инструкция по запуску тестов
Для локального запуска всех тестов выполните команду:
```bash
flutter test
```

Для получения расширенного отчета:
```bash
flutter test --reporter expanded
```

## 2. Тестовая инфраструктура
- **Unit-тесты**: стандартный пакет `flutter_test`.
- **Integration-тесты**: использование `firebase_auth_mocks` для имитации работы `Firebase`.
- **UI-тесты**: использование `WidgetTester` и `Provider` для тестирования виджетов в изолированной среде.

## 3. Список тестов (10 шт.)

- Unit-тесты (Логика валидации):

    - Проверка пустого email (ожидается ошибка).

    - Проверка невалидного формата email (ожидается ошибка).

    - Проверка корректного email (успешный проход).

    - Проверка минимальной длины пароля (валидация на 6+ символов).

- Integration-тесты (Работа модулей)

    - Успешный вход в AuthRepository (проверка связи с Firebase).

    - Выход из аккаунта (проверка очистки состояния currentUser).

    - Проверка корректности UID (соответствие данных из Auth данным в Repository).

- UI-тесты (Пользовательские сценарии)

    - Проверка наличия всех элементов на экране логина (поля, кнопки).

    - Сценарий ввода данных (имитация набора текста в поля).

    - Проверка состояния контроллеров (очистка или начальное состояние полей).

## 4. Необходимые данные
Тесты используют Mock-объекты, поэтому наличие реального интернета или аккаунтов Firebase не требуется. Все зависимости внедряются через конструкторы репозиториев.
