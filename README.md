<h2>Getting Started</h2>

1. Clone the repo

   ```bash
   git clone https://github.com/KhaidarovNurlan/Campus911.git
   ```
2. Install all dependencies

   ```bash
   flutter pub get
   ```
3. Paste your own `android/app/google-service.json` and `lib/firebase_options.dart`

4. Create your own `.env`

   ```env
   GEMINI_API_KEY='...'
   ```
5. Start an application

   ```bash
   flutter run
   ```
